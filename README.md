# Some free sauce skills

Some public skills for general use. Modern LLM skills offer a great way
to be "light-touch opinionated" over the top of an existing project or 
in conjunction with other skills or project guidelines.

## Skills / thinking

### drupal-content-modeling

I'm pretty fussy about Drupal content modeling, and a lot of that boils down
to field and entity reuse. I have a lot of code history where I have tried to
template the content model of Drupal site but every Drupal site is (and should
be) different depending on what problem it is solving. Hence applying modelling
to a site can be more of a philosophy than a set of instructions. - Si

### tailwind-theming 

I don't generally want to use someone else's tailwind templates when it comes
platforms I'm comfortable with. I find that existing Tailwind templates are 
a bit of a mess with anti-patterns that Tailwind is supposed to avoid if
done correctly. In addition there might be some quirks I wanted to capture
in the stub themes, such as in Drupal how might you pick up on tailwind classes
which are added via ckeditor snippets? - Si
